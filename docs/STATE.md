## Blockers / Waiting on Sean

- **Blackout detection is ~130s on a bars-only feed** (deferred from PR #7, revisit in Phase 9 / before live money). Subscribing to the trade tape + a 30s window buys it back to ~35s, and the review lens rates that highest-priority for live trading. Deferred because IEX tape prints thin out in extended hours, so a 30s window on trades may false-trip pre/post-market — the same class of bug PR #7 exists to kill, and not worth changing data volume days before a proof run. **What makes ~130s tolerable today:** signals are bar-driven, so with the market-data socket dark no signals fire at all. That guarantee dies the moment a strategy emits on a fill or a timer — revisit then, not later.

Runbook in `MANUAL-SETUP.md`. It proves the real Alpaca round-trip — `position_intent=*_to_close` semantics, the held-qty cancel race, stream→ledger timing — which offline tests can only simulate.
